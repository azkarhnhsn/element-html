Elemen Tabel

Elemen HTML dalam Membuat Tabel

Tabel pada dasarnya digunakan untuk mengelompokkan suatu data secara terstruktur yang terdiri dari baris, kolom dan sel

Dalam membuat tabel dalam HTML ada beberapa tag yang harus diketahui seperti :

  • <table> : Tag ini digunakan untuk membuat tabel
  • <tr> : Tag ini digunakan untuk membuat baris pada tabel
  • <td> : Tag ini digunakan untuk membuat sel/kolom data pada tabel

Seiring dengan perkembangan dan kebutuhan akan tabel, HTML juga menyediakan elemen-elemen opsional lain dalam pembuatan tabel seperti :

  • <th> : Tag ini digunakan untuk membuat sel/kolom header pada tabel
  • <thead> : Tag ini digunakan untuk mengelompokkan baris header pada tabel
  • <tbody> : Tag ini digunakan untuk mengelompokkan baris isi pada tabel
  • <tfoot> : Tag ini digunakan untuk mengelompokkan baris footer pada tabel

Menggabungkan Sel pada tabel HTML

Saat membuat tabel, terkadang kita dihadapkan akan kebutuhan untuk menggabungkan beberapa sel menjadi satu. Untuk menggabungkan beberapa sel menjadi satu pada suatu tabel, HTML menyediakan beberapa atribut yang bisa kamu gunakan seperti rowspan dan colspan

  • rowspan : Atribut ini digunakan untuk menggabungkan beberapa sel pada kolom (bawah) menjadi satu
  • colspan : Atribut ini digunakan untuk menggabungkan beberapa sel pada baris (samping) menjadi satu

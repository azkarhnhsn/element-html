Elemen Link

Elemen HTML dalam Membuat Tautan

Link (tautan) pada dasarnya digunakan untuk menghubungkan satu halaman web dengan halaman web lain, baik itu halaman dalam website yang sama maupun website lain.

Berikut sintaks dalam menggunakan elemen link:

  • <a> : Tag ini digunakan untuk membuat tautan pada halaman web
  • href : Atribut ini digunakan untuk menentukan alamat tujuan dari tautan tersebut
  • target : Atribut ini digunakan untuk menentukan cara tautan dibuka, misalnya "_blank" untuk membuka di tab baru

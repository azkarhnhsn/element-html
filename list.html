List

Pengertian List

List digunakan untuk menampilkan beberapa item dalam bentuk daftar. HTML menyediakan beberapa jenis list, di antaranya unordered list dan ordered list.

Unordered List

Unordered list menggunakan tag ul dan biasanya ditampilkan dengan tanda bullet.

  • HTML
  • CSS
  • JavaScript

Ordered List

Ordered list menggunakan tag ol dan biasanya ditampilkan menggunakan nomor secara berurutan.

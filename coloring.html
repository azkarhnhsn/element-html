Elemen Coloring

Elemen HTML dalam Memberi Warna

Coloring pada dasarnya digunakan untuk memberikan warna pada teks, latar belakang (background), maupun garis pada halaman web agar tampilan lebih menarik dan mudah dibedakan.

Berikut atribut yang digunakan dalam memberi warna pada elemen HTML:

  • style : Atribut ini digunakan untuk menuliskan aturan CSS langsung pada suatu elemen HTML
  • color : Properti CSS yang digunakan untuk mengatur warna teks
  • background-color : Properti CSS yang digunakan untuk mengatur warna latar belakang suatu elemen

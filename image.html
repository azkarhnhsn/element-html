Elemen Gambar

Elemen HTML dalam Menampilkan Gambar

Gambar pada dasarnya digunakan untuk menampilkan suatu gambar pada halaman web.

berikut sintaks dalam menggunakan elemen image:

  • <img> : Tag ini digunakan untuk menampilkan gambar pada halaman web
  • src : Atribut ini digunakan untuk menentukan sumber gambar yang akan ditampilkan
  • alt : Atribut ini digunakan untuk memberikan teks alternatif pada gambar jika gambar tidak dapat ditampilkan
  • width : Atribut ini digunakan untuk menentukan lebar gambar
  • height : Atribut ini digunakan untuk menentukan tinggi gambar

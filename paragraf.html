Paragraf

Pengertian Paragraf

Tag paragraf digunakan untuk menampilkan teks dalam bentuk paragraf pada halaman HTML.

Contoh Penggunaan Paragraf

HTML digunakan untuk membuat struktur dasar sebuah halaman web. Salah satu elemen yang digunakan dalam HTML adalah paragraf.

Setiap tag p dapat digunakan untuk membuat sebuah paragraf baru. Dengan menggunakan paragraf, teks dapat ditampilkan secara lebih terstruktur.

Contoh ini menunjukkan penggunaan beberapa paragraf dalam satu halaman HTML.
